## Описание проекта

**QUBIC — QR Code Studio** — это полноценное настольное приложение для генерации, визуальной кастомизации, предпросмотра, сохранения и управления QR-кодами полностью в офлайн-режиме. Приложение сочетает премиальный тёмный интерфейс, модульную архитектуру Python и высокую надёжность сканирования создаваемых кодов.

## Основные возможности

- **7 поддерживаемых типов QR-кодов**:
  - **URL / Веб-сайт** — автоматическое добавление `https://` и опциональная строгая проверка формата ссылки.
  - **Обычный текст** — многострочное текстовое поле со счётчиком символов.
  - **Wi-Fi сеть** — генерация стандартного载荷 `WIFI:` с поддержкой `WPA/WPA2/WPA3`, `WEP`, открытых и скрытых сетей.
  - **Эл. почта (Email)** — формирование `mailto:` с адресом получателя, темой и текстом письма.
  - **Номер телефона** — быстрый набор номера (`tel:`).
  - **SMS-сообщение** — формирование `SMSTO:` с номером телефона и необязательным текстом сообщения.
  - **Визитка (vCard 3.0)** — карточка контакта с именем, фамилией, телефоном, электронной почтой, организацией и веб-сайтом.
- **Гибкая визуальная настройка**:
  - Настройка **цвета модулей** и **цвета фона** (ввод HEX с валидацией, палитра выбора цвета, недавние цвета, проверка контрастности и сброс по умолчанию).
  - **4 стиля модулей**: *Классический*, *Скруглённый*, *Точки* и *Мягкий* с сохранением геометрии поисковых квадратов для стабильного чтения сканерами.
  - **4 уровня коррекции ошибок**: `L` (~7%), `M` (~15%, по умолчанию), `Q` (~25%) и `H` (~30%).
  - **Выбор разрешения**: `256 × 256`, `512 × 512`, `1024 × 1024`, `2048 × 2048` пикселей, а также произвольный размер (`128`–`4096` пикс.).
  - **Логотип в центре**: загрузка изображений `PNG` и `JPG`, автоматическое масштабирование, регулировка размера, белая подложка позади логотипа и автоматическое повышение коррекции ошибок до уровня `H`.
- **Система экспорта**:
  - Сохранение в форматах **PNG** (с поддержкой прозрачного фона), **JPG** и **SVG** (чистая векторная графика).
  - Автоматические имена файлов с датой (например, `qubic_qr_2026-11-07.png`), копирование в буфер обмена и быстрый переход к папке сохранения.
- **Локальная история (SQLite) и готовые шаблоны**:
  - Поиск по истории, фильтрация по типу QR-кода, сортировка (сначала новые / старые), повторная загрузка в Генератор, быстрый экспорт и очистка истории с подтверждением.
  - Набор из 7 готовых шаблонов для быстрого старта.
- **Полная локализация и темы оформления**:
  - Полная поддержка **английского** и **русского** языков с переключением на лету без перезапуска программы.
  - Поддержка **Тёмной** (по умолчанию), **Светлой** и **Системной** темы.

## Технологический стек

- **Python 3.11+** — ядро приложения и модульная архитектура
- **PySide6 (Qt 6)** — графический интерфейс и кастомные таблицы стилей QSS
- **qrcode[pil] и Pillow** — генерация матриц ISO/IEC 18004 и отрисовка стилей
- **SQLite 3** — локальное хранение истории и параметров
- **PyInstaller** — сборка автономного `.exe` файла для Windows
- **pytest / unittest** — автоматизированное тестирование

## Установка и запуск

### Предварительные требования

- **Операционная система**: Windows 10 или Windows 11 (также работает на Linux и macOS)
- **Python**: версия 3.11 или новее
- **Git**: необязательно (для клонирования репозитория)

### Вариант 1: Установка из GitHub через Git

Выполните следующие команды в командной строке (cmd) или PowerShell:

```bash
git clone https://github.com/kemorovv/QUBIC.git
cd QUBIC
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

*(Если фактическое имя репозитория отличается, замените `QUBIC` в командах выше на соответствующее имя.)*

### Вариант 2: Запуск без клонирования (скачивание ZIP-архива)

1. Перейдите в профиль разработчика на GitHub (`https://github.com/kemorovv`) и откройте репозиторий проекта.
2. Нажмите **Code** → **Download ZIP** и распакуйте архив в удобную папку.
3. Откройте терминал или PowerShell в папке с распакованным проектом.
4. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
5. Запустите приложение:
   ```bash
   python main.py
   ```

## Сборка исполняемого файла (.exe)

Вы можете собрать **QUBIC** в единый автономный исполняемый файл Windows, не требующий установленного Python на компьютере пользователя.

### Сборка через конфигурацию `build/qubic.spec` (Рекомендуется)

Файл спецификации автоматически включает папки `assets/`, `locales/`, `src/styles/` и `config.json`:

```bash
pyinstaller --noconfirm build/qubic.spec
```

### Прямая команда PyInstaller

```bash
pyinstaller --noconfirm --windowed --onefile --name QUBIC --icon assets/icon.ico --add-data "assets;assets" --add-data "locales;locales" --add-data "src/styles;src/styles" --add-data "config.json;." main.py
```

Готовый файл будет создан по пути `dist/QUBIC.exe`.
